# Pearls

An unofficial port of the Mutable Instruments Beads granular processor (DSP by
Emilie Gillet) to the Nebulae v2.

Pearls needs a compiled Csound plugin, so unlike the other instruments in this
folder it is not just an `.instr` file. The instrument file, the source code
and the install instructions are in
[`Code/beads_port`](../../Code/beads_port/README.md).
